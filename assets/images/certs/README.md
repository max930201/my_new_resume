# 證書圖片資料夾

檔名請對應 `config/certificates.json` 裡每一筆的 `image` 欄位，例如 `cert-01.jpg`。

在圖片放入之前，該筆證書會自動顯示「尚未上傳證書圖片」的提示文字，不會出現破圖。

## 如何新增一筆證照

1. 複製 `config/certificates.json` 裡的其中一個物件（`{ ... }`），貼在陣列最後面，記得中間用逗號分隔
2. 把 `id` 改成不重複的名稱（例如 `cert-03`）
3. 填入 `name`（證照全名）、`issuer`（發證單位）、`date`（取得日期）
4. 把 `image` 改成對應的檔名，並把圖片放進這個資料夾
